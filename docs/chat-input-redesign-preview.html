⌨ 模拟键盘弹出 / 收起（观察按钮位置是否跳变）

1 · 现状 问题定位

输入区由 输入框（含 leading 快捷消息 / trailing 全屏+发送） 和 底部工具行 两部分组成，工具行随键盘状态显示/隐藏。

四个具体问题：
① 「＋」与发送按钮相邻仅 8dp（30dp 圆形按钮，Material 规范建议相邻触控目标 ≥ 8dp 间隙或 ≥ 16dp），两者视觉相近、同一样式，极易误触；
② 发送按钮存在两个位置：键盘弹出时出现在输入框 trailing，键盘收起时出现在底栏最右——位置随 IME 状态“跳跃”，肌肉记忆失效；
③ 一行塞了 7 个控件（模型/搜索/推理/优化/＋/麦克风/发送），层级不分，视觉杂乱；
④ 键盘弹出时 「＋」入口整个消失——打字中途想加附件需要先收键盘再点＋，流程断裂。

交互观察

点击下方「模拟键盘弹出」：底栏整行消失，发送按钮从右下角“跳”到输入框内右上角。这就是问题 ② 的实际体感。

2 · 方案 A：发送固定右上 + 「＋ / ⚡」对调 已落地

最终形态：发送按钮唯一、常驻输入框右上角；「＋」常驻输入框左侧 leading；快捷消息 ⚡ 移到工具行，与「＋」对调位置。

  • 发送按钮固定输入框右上（键盘弹出/收起位置不变），工具行不再放发送
  • 「＋」移到输入框左侧（原快捷消息的位置）：常驻可见，键盘弹出时也能直接加附件，无需额外入口
  • ⚡ 快捷消息移到工具行（原「＋」的位置），与模型/搜索/推理同区
  • 「＋」与发送分处输入框两端，物理上不可能误触；子代理运行中在「＋」左侧附加子代理图标
  • 「＋」面板改版：新增网络搜索服务卡片；排序为 MCP 服务 → 网络搜索 → 扩展管理 → 工作区 → 信任文件夹 → 知识库；全部统一为主标题+次标题宽卡片，扩展管理副标题展示 技能/快捷消息/模式注入/世界书 已开数量（点左侧 ＋ 可实际展开预览）
// ChatInput.kt 已落地改动 leadingIcon = { ＋ MoreButton } // 原 ⚡ 快捷消息位置，常驻 trailingIcon = SendButton() // 常驻，去掉 imeTargetVisible 条件 // 工具行：⚡ QuickMessageButton 取代原 ＋； // 删除工具行内的 SendButton（发送唯一在输入框右上）
✅ 已实现发送位置恒定＋/发送彻底分离键盘态附件入口补齐

误触分析

＋ 移入输入框最左端，发送固定在输入框右上角，两者之间隔着一整条文本框；工具行内的 ⚡ 与发送也不再同侧。发送按钮在全部 IME 状态下只有一个、一个位置。

3 · 方案 B：全入输入框（主流 IM 风）

核心思路：干掉整个底栏，所有辅助功能收进输入框 leading 的「＋」展开面板，输入区只剩一行。

  • 输入框结构：leading「＋」（点开功能面板：文件/图片/模型/搜索/推理/优化/语音/快捷消息）→ 文字区 → trailing 发送（常驻）
  • 键盘弹出/收起输入区 零变化，布局最稳定
  • ＋ 在左端、发送在右端，间距为整个输入框宽度
  • 与微信 / Telegram / DeepSeek 一致的心智模型，用户零学习成本
// 底栏整个删除 // TextInputRow: leadingIcon = MoreButton { showPanel() } // 原快捷消息入口并入面板 trailingIcon = { SendButton() } // 常驻，无 IME 条件
最简洁（一行）位置零跳变符合主流习惯键盘态功能完整
高频功能多一步展开模型/搜索切换变繁琐改动量中等

试试看

点击输入框左侧的 ＋ 展开功能面板；点击面板外关闭。发送按钮始终固定在输入框右上。

4 · 方案 C：三键底栏 + 工具抽屉

核心思路：底栏只保留三个主键——🛠 工具抽屉 / 🎙 语音 / ↑ 发送，所有低频功能收进抽屉；三键等距 ≥ 12dp。

  • 底栏：🛠（点击弹出横向抽屉：📎 附件 / ★ 模型 / 🔍 搜索 / 🧠 推理 / ✨ 优化 / ⛶ 全屏）— 12dp — 🎙 语音 — 12dp — ↑ 发送
  • 发送仍在底栏最右（现状位置），但只出现一次、且与 🎙 距离 12dp
  • 常用项（语音、发送）保持一级入口，低频项（模型、搜索）收进抽屉，回车即收
// 底栏重构： Row { ToolDrawerButton(...) // 抽屉浮层 Spacer(12.dp) AsrButton(...) Spacer(12.dp) SendButton(...) // 唯一发送 } // 删除输入框 trailing 的 SendButton 分支
底栏视觉最干净只保留一个发送触控间距达标
模型切换多一步抽屉是新增 UI 需打磨改动量中等

试试看

点击底栏左侧 🛠 展开工具抽屉；🎙 和 ↑ 始终原地不动。

5 · 方案 D：底栏常驻（不随键盘隐藏）

核心思路：底栏永远显示（键盘弹出时顶到键盘上方），所有按钮位置在任何状态下都不变；「＋」与发送间距拉到 16dp。

  • 删除 AnimatedVisibility(!imeTargetVisible) 的隐藏逻辑，底栏常驻
  • 输入框 trailing 不再放发送，发送唯一在底栏最右
  • 「＋」与发送之间改 16dp 间距，达到 Material 相邻触控目标推荐值
  • 键盘弹出时底部可用高度减少约一行，但换来位置绝对稳定
// 底栏： AnimatedVisibility(visible = !imeTargetVisible) → Row { ... } // 去掉动画隐藏，直接常驻 // 间距：8.dp → 16.dp Spacer(Modifier.width(16.dp))
位置零跳变改动最小无新增 UI 概念
打字时底部占用多一行＋ 与 ↑ 仍同侧（间距 16dp）

误触分析

16dp 缝隙 + 发送改为实底圆形/＋保持描边，视觉层级拉开；但仍同处右侧，误触概率下降而非消除。若想根治误触，选方案 A。
