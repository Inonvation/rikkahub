## 二、界面偏好设置 = 二级分类页（本次核心）

`SettingPreferencesUIPage` 改为 **9 个二级入口**，每个入口 → `SettingDisplayGroupPage(group)` 显示该分组设置项：

| 二级入口 | 子页设置项（均带图标、开关对齐） |
|---|---|
| 布局 | 平板适配、消息跳转器、跳转器位置、自动滚动 |
| 消息气泡 | 显示用户头像、显示助手气泡、气泡透明度 |
| 消息信息 | 模型图标、模型名、消息时间、Token 用量 |
| 思考 | 显示思考内容、自动折叠思考、自动折叠步骤、思考冻结条 |
| 字体 | 聊天字体、自定义字体、字号 |
| 渲染 | LaTeX 渲染、应用图标加载指示、模糊效果 |
| 代码显示 | 自动换行、自动折叠、显示行号 |
| TTS 播放 | 仅朗读引用、朗读括号外、生成后自动播放 |
| 触觉反馈 | 触觉反馈、界面触觉反馈、生成开始/完成反馈 |

实现：`Screen.SettingDisplayGroup(group: String)` 单路由 + `SettingDisplayGroupPage.kt` 内 `when(group)` 分发，9 组共用同一页面骨架，条件子项（跳转器位置、通知实时更新等）保持原有联动逻辑。

## 三、行为与通知（合并页）

`SettingPreferencesGeneralPage` 标题改为「行为与通知」，四分区（均带图标）：
- **会话**：启动时创建新会话
- **输入**：回车发送、长文本粘贴（+阈值）、跳过图片裁剪、音量键滚动（+比例）
- **文档处理**：扫描 PDF 文字识别
- **通知**：消息生成完成通知、实时更新通知（保留通知权限申请逻辑）

原 `SettingPreferencesNotificationPage` 不再有首页入口，文件与路由保留（无引用风险）。

## 四、分类原则与开关对齐

- **界面偏好设置** = 显示/外观类（布局、气泡、信息、思考、字体、渲染、代码、TTS、触觉）
- **行为与通知** = 操作/输入/文档/通知类
- 所有设置项统一 `leadingContent` 图标（HugeIcons），开关列严格对齐（修复平板适配、PDF OCR 等错位）
